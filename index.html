How to Deploy to Vercel in 2 Minutes

No command-line needed • 100% Free Tier

Why Vercel?

Vercel offers global edge hosting, instant SSL (https), and custom domains without maintaining servers. Because this entire site is compiled into a single clean file, deployment is effortless.

1

Save this file as index.html

Place it in a new folder on your computer (e.g. my-portfolio/index.html).

2

Sign up at vercel.com

Log in via your GitHub or Google account in 10 seconds.

3

Deploy: Drag & Drop or GitHub Repo

Either create a GitHub repo and click "Import" on Vercel, or drag your folder directly into the Vercel dashboard. It detects static HTML automatically!

4

Generate your Resume QR Code

Vercel will give you a live link like https://alex-rivera.vercel.app. Open the QR Code tool on this page, paste that URL, and download your high-res print QR!
